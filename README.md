# kino-oynasi

Create a modern, responsive movie website called CineClub.

IMPORTANT:

The website UI must be entirely in Uzbek language.

The prompt itself is in English, but all visible text, buttons, menus, labels, notifications and movie information should be in Uzbek.

Design should be modern, cinematic, dark and premium.

The website should work perfectly on both desktop and mobile.

Main Concept

CineClub is a movie discovery and streaming-style website where users can browse movies, search for films, view movie details, and watch available movie content.

Homepage

Create a beautiful dark cinematic homepage with:

CineClub logo in the header

Navigation menu:

Bosh sahifa

Filmlar

Janrlar

Seriallar

Saralanganlar

Search bar with Uzbek placeholder: "Film qidirish..."

Large hero section featuring a popular movie

Movie title, short description, genre, rating and release year

Buttons:

"Tomosha qilish"

"Batafsil"

Sections:

"Mashhur filmlar"

"Yangi filmlar"

"Eng yuqori baholanganlar"

"Siz uchun tavsiya etiladi"

Movie Cards

Each movie card should contain:

Movie poster

Movie title

Release year

Genre

Rating

Hover animation

"Tomosha qilish" button

Use realistic placeholder movie data and high-quality movie poster placeholders.

Description

Similar movies section

Search

Users should be able to search movies by title.
Show Uzbek messages such as:

"Film topilmadi"

"Qidiruv natijalari"

Large video player placeholder

Only use legally available or placeholder video content. Do not include copyrighted movies without proper rights.

Mobile-friendly bottom/navigation menu if appropriate

Branding

Website name: CineClub

Logo style:
A modern cinema-inspired logo with a film/play icon and the text "CineClub".

The final result should feel like a professional modern Uzbek movie platform, similar in quality to a premium streaming service, while using Uzbek language throughout the entire interface.
